# 📊 Анализ ресурсов и рекомендация по конфигурации сервера (Selectel)

Данные получены путем мониторинга запущенных Docker-контейнеров (`docker stats`) на тестовом сервере под реальной нагрузкой (включая фоновые запросы и сканирование ботами).

| Компонент | Контейнер | Потребление RAM (MEM USAGE) | Примечание |
| :--- | :--- | :--- | :--- |
| **Backend** | `antoshkin-pwa-card-app-1` (FastAPI + Python 3.12) | **~67.7 MiB** | Основное ядро приложения |
| **Proxy** | `antoshkin-pwa-card-nginx-1` (Nginx) | **~10.3 MiB** | Reverse proxy, статика, SSL |
| **ИТОГО Приложение** | | **~78 MiB** | Суммарное потребление стека |

> **Важно:** Потребление CPU в состоянии покоя составляет < 0.2%, что указывает на высокую эффективность архитектуры. Пики CPU возможны только при генерации тяжелых отчетов или массовых одновременных входах, но для данного типа нагрузки (PWA карты) они кратковременны.

```bash
echo "=== Контейнеры ===" && \
docker stats --no-stream && \
echo -e "\n=== Логи (последние 10 строк) ===" && \
docker logs --tail 10 antoshkin-pwa-card-app-1 && \
echo -e "\n=== Свободная память на хосте ===" && \
free -h
```

## 2. Рекомендованная конфигурация Selectel

На основе фактических метрик, для стабильной работы в Production рекомендуется следующая конфигурация тарифа **Shared**:

### ✅ Оптимальный выбор (Баланс цена/надежность)

*   **Тариф:** Shared
*   **Доля vCPU:** 10% (Гарантированная доля ядра 2.2–2.4 ГГц)
*   **vCPU:** 1 ядро
*   **RAM:** **512 МБ** *(Минимально достаточный объем)*
    *   *Обоснование:* Приложение занимает ~78 МБ. ОС + системные процессы займут ~100-150 МБ. Остается ~280 МБ запаса, что позволяет выдерживать кратковременные пики нагрузки без использования Swap.
*   **Диск:** 5 ГБ HDD Базовый *(SQLite база данных занимает мало места, рост ожидается медленным)*
*   **Сеть:**
    *   Тип: Приватная подсеть (безопасность)
    *   IP: **Публичный IPv4** (Обязательно для доступа клиентов из интернета и работы HTTPS/Let's Encrypt)

## 3. Риски и ограничения конфигурации 512 МБ RAM

Хотя текущее потребление (~78 МБ) значительно ниже лимита (512 МБ), следует учитывать следующие факторы:

1.  **Запас прочности:** Запас составляет ~85%. Этого достаточно для стандартной нагрузки.
2.  **Рост нагрузки:** При увеличении числа одновременных пользователей (>100 req/sec) или добавлении тяжелых фоновых задач (например, генерация сложных CSV отчетов на лету) потребление памяти может вырасти до 200-300 МБ. Даже в этом случае 512 МБ останется достаточным.
3.  **Swap:** Если вдруг произойдет утечка памяти или аномальный пик, система начнет использовать Swap (если он включен на уровне ОС хоста), что замедлит отклик, но не уронит сервис. В Selectel Shared тарифах Swap обычно предоставляется автоматически.

## 4. Итоговый вердикт

**Конфигурация с 512 МБ RAM является полностью достаточной для запуска `Antoshkin Loyalty Card PWA` в Production.**

Переплачивать за 1 ГБ или 2 ГБ RAM на данном этапе нет необходимости, так как приложение оптимизировано и использует легковесный стек (FastAPI + SQLite + Nginx). Мониторинг следует настроить на алерт при превышении порога использования RAM > 400 МБ.
